# Encuesta final · Aula 2

La encuesta queda disponible en la planilla compartida. Cada alumno debe elegir una alternativa por pregunta y registrar sus letras en una nueva fila de la pestaña **Respuestas**.

## Campo obligatorio

- **Nombre y apellido**

## Preguntas

1. **¿Cuál es la función principal de un anuncio?**
   - Generar flujo hacia el negocio. ✓
   - Cerrar una venta inmediatamente.
   - Conseguir seguidores sin contexto.
   - Reemplazar el trabajo del negocio.

2. **¿Qué necesitamos antes de trabajar una idea con IA?**
   - Un briefing claro. ✓
   - Una imagen terminada.
   - Un carrusel publicado.
   - Un listado de seguidores.

3. **¿Qué debe generar el prompt corregido de la clase 1?**
   - Solamente ideas creativas. ✓
   - Copy, imágenes y publicación final.
   - Una pieza lista para publicar.
   - Un carrusel completo.

4. **¿Qué recibe el proyecto de Copy para empezar?**
   - Una idea creativa ya seleccionada. ✓
   - Una imagen terminada.
   - Solo el logo.
   - Una referencia sin contexto.

5. **¿Qué incluye la planificación creativa?**
   - Formato, textos, descripción visual y CTA. ✓
   - Solo el logo y los colores.
   - Únicamente la descripción de la publicación.
   - Todas las imágenes generadas.

6. **¿Cuántas opciones propone el proyecto de Copy?**
   - Tres opciones dentro del mismo concepto. ✓
   - Una única opción definitiva.
   - Diez imágenes terminadas.
   - Dos anuncios sin copy.

7. **Si el formato no está informado, ¿qué debe preguntar Copy?**
   - Si será Feed, Stories o ambos; y si será una pieza o carrusel. ✓
   - Qué filtro tiene la foto.
   - Qué música se usará.
   - Qué día se publicará.

8. **Después de aprobar una opción de Copy, ¿qué se prepara?**
   - La descripción de la publicación. ✓
   - Las imágenes finales.
   - Un logo nuevo.
   - Una nueva investigación.

9. **¿En cuántos bloques de código se entrega el resultado final de Copy?**
   - Dos: planificación creativa y descripción de la publicación. ✓
   - Uno: una lista de ideas.
   - Tres: investigación, logo y diseño.
   - Cuatro: una imagen por formato.

10. **¿Qué llevamos desde Copy al proyecto de Diseño?**
    - La planificación creativa. ✓
    - La publicación ya subida.
    - Todas las opciones sin elegir.
    - El briefing vacío.

11. **¿Para qué sirven las referencias visuales?**
    - Para orientar el lenguaje visual de una pieza propia. ✓
    - Para copiar una campaña completa.
    - Para reemplazar el logo.
    - Para evitar el briefing.

12. **¿Qué fuentes deben estar disponibles en el proyecto de Diseño?**
    - Logo original y referencias visuales. ✓
    - Solo un texto de ejemplo.
    - Fotos personales del alumno.
    - Las respuestas de la encuesta.

13. **¿Qué prompt se usa en GPT Work y GPT Chat?**
    - El mismo prompt del proyecto. ✓
    - Un prompt totalmente diferente en cada uno.
    - Ningún prompt en GPT Chat.
    - Solo un prompt de imágenes.

14. **En GPT Chat, antes de pegar la planificación creativa, ¿qué preguntamos?**
    - ¿Cuáles son las fuentes y las instrucciones de este proyecto? ✓
    - ¿Podés generar todo el carrusel en un archivo?
    - ¿Podés cambiar el concepto?
    - ¿Cuántos seguidores tiene la cuenta?

15. **¿Qué hacemos después de que GPT Chat responda sobre las fuentes e instrucciones?**
    - Pegamos la planificación creativa. ✓
    - Creamos otro briefing desde cero.
    - Pedimos todas las imágenes juntas.
    - Descartamos las referencias.

16. **¿Cómo se genera un carrusel?**
    - Una imagen independiente por cada página. ✓
    - Todas las páginas dentro de una sola imagen.
    - Una imagen sin planificación.
    - Solo con texto, sin imagen.

17. **¿Cómo avanzamos al generar varias imágenes?**
    - Revisamos una y luego pedimos la siguiente. ✓
    - Pedimos todas al mismo tiempo.
    - Publicamos la primera sin revisar.
    - Cambiamos el concepto en cada página.

18. **¿Qué tipo de ajustes hacemos sobre una imagen generada?**
    - Cambios puntuales. ✓
    - Un concepto totalmente nuevo en cada ajuste.
    - Ninguna revisión.
    - Otra investigación de mercado.

19. **¿Para qué adaptamos una pieza?**
    - Para usarla en Feed o Stories manteniendo el concepto. ✓
    - Para cambiar el logo de la empresa.
    - Para eliminar la planificación.
    - Para evitar usar referencias.

20. **¿Para qué sirve programar una tarea?**
    - Para organizar una acción que se repetirá en un momento definido. ✓
    - Para generar imágenes sin instrucciones.
    - Para reemplazar el briefing.
    - Para omitir la revisión del resultado.

## Enlaces configurados

- `formUrl`: abre la pestaña **Cuestionario** para los alumnos.
- `sheetUrl`: abre la pestaña **Respuestas** desde `/admin/`.
