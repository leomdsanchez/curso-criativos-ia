# Criativos con IA — Clase 1

Presentación interactiva en React + Vite para la primera clase del curso **Criativos con IA**.

## Uso local

```bash
npm install
npm run dev
```

## Controles

- `→`, `Espacio`, `Enter`: avanzar
- `←`, `Backspace`: volver
- `Home` / `End`: inicio o final
- `F`: pantalla completa

## Publicación

El repositorio incluye un workflow de GitHub Actions que construye el proyecto y publica `dist` en GitHub Pages.

La URL prevista es:

`https://leomdsanchez.github.io/curso-criativos-ia/`
